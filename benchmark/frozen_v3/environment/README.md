# Frozen V3 Environment Record

- `requirements.txt` is the repository requirement set copied at freeze.
- `requirements-lock.txt` records the exact versions used for the Revision 2
  audit and Dev13 execution.
- `python-version.txt` records the repository Python version declaration.

Exact package versions observed in the active freeze environment are recorded
in `benchmark/frozen_v3/freeze_manifest.json`.
